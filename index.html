JavaScript - Cuestionario personalizado.

En esta etapa vas a programar la lógica del juego de preguntas utilizando JavaScript. El objetivo es que, cuando el usuario presione el botón , el programa detecte cuáles respuestas son correctas, calcule el puntaje obtenido, lo guarde en el navegador y luego muestre el resultado en el documento final.

Requisitos técnicos.

  1. Detectar el evento click en el botón .

  2. Comprobar si los Checkbox() correctos fueron seleccionados.

  3. Sumar un punto por cada respuesta correcta marcada.

  4. Guardar el puntaje total usando localStorage().

  5. Redirigir automáticamente al documento final donde se mostrará el puntaje.

Ayudas

Vincular JavaScript.

Para vincular un script a nuestro documento HTML se utiliza la etiqueta script.

Código de ejemplo: 

    <!-- Enlazar JavaScript -->
    <script src="main.js"></script>

Atención

Asegurate de que el nombre del archivo sea el mismo que colocaste en el atributo src y que ambos archivos se encuentren en la misma carpeta del proyecto.

La vinculación del archivo JavaScript debe realizarse al final del <body>, antes de la etiqueta de cierre </body>.



addEventListener().

Se usa para controlar eventos, por ejemplo cuando el usuario hace click en el botón . Cuando ocurre ese evento, se ejecuta la función que definas.

Código de ejemplo: 

    let boton = document.getElementById('btnEnviar');  // En esta linea se selecciona el elemento HTML por el ID
boton.addEventListener("click",()=>{
        //   Código que se ejecuta al hacer click en "Enviar".    
});



.checked

La propiedad .checked permite comprobar si un elemento de tipo checkbox o radio está seleccionado.

Devuelve un valor booleano:

  • true → Está seleccionado.

  • false → No está seleccionado.

Código de ejemplo: 

    console.log(document.getElementById("aceptar").checked);

Mostrará true por consola, si el checkbox está seleccionado. Y false si el checkbox no está seleccionado.


localStorage().

Guarda información en el memoria del navegador. Los datos guardados con localStorage permanecen aunque se recargue el documento. 

    let puntaje = 0;
    if(respuesta1) puntaje++  // Si respuesta1 da "true", se sumara 1 a la variable puntaje.
    localStorage.setItem("total", puntaje); // Guarda el valor de la variable puntaje en el espacio de memoria del navegador declarado "total".
    
    // En el documento final.
    let puntos = localStorage.getItem("total");    // Con getItem busca en la memoria alguna dirección que se llame "total", y la asigna a la variable puntos.
    console.log(`Tu puntaje fue:${puntos}`);
